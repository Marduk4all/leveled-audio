**English** · [Deutsch](#deutsch)

First release of **Leveled Audio**, batch processing for speech recordings (WAV), offline and without any installation. It comes with a desktop app (English/German) and the command-line tool `leveled-audio`.

### Features
- High-pass, noise reduction with automatic noise profile, handling-noise detection and reduction
- Adaptive leveler (default 130 %: also evens out large microphone-distance changes)
- Compressor, optional pause gate
- Loudness normalization (EBU R128, per file or as album) and true-peak limiter
- Presets (`podcast-stereo`, `podcast-mono`, `podcast-kraeftig`, `ebu-r128`) and your own TOML presets
- JSON report with schema
- Desktop app: exports next to the original file (`name-leveled-<preset>.wav`)

### Which file do I need?
| Your computer | Download this file |
|---|---|
| **Mac** (any model, Apple Silicon or Intel) | `leveled-audio-0.1.0-universal-apple-darwin.tar.gz`, contains `Leveled Audio.app` |
| **Windows** 10/11 | `leveled-audio-0.1.0-x86_64-pc-windows-msvc.zip`, contains `leveled-audio-gui.exe` |
| **Linux desktop** (Ubuntu, Fedora, Debian …) | `leveled-audio-0.1.0-x86_64-unknown-linux-gnu.tar.gz`, desktop app |
| **Linux server / Docker**, command line only | `leveled-audio-0.1.0-x86_64-unknown-linux-musl.tar.gz`, runs on any Linux without extra libraries |

You can ignore the other files. `aarch64-apple-darwin` and `x86_64-apple-darwin` are Mac builds for only one processor type (the universal file covers both), `SHA256SUMS.txt` is for verifying downloads, and "Source code" is for developers. ("unknown" in the Linux names is just the technical way of saying "any vendor".)

**macOS:** The app is not notarized. The first time, right-click it → Open → Open.
**Windows:** SmartScreen may warn about an unknown publisher: "More info" → "Run anyway".

Checksums: `SHA256SUMS.txt`. Guide: `GUIDE.md` (English) / `ANLEITUNG.md` (German) in the archive.
