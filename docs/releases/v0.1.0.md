**English** · [Deutsch](#deutsch)

First release of **Leveled Audio**, batch processing for speech recordings (WAV), offline and without any installation. It comes with a desktop app (English/German) and the command-line tool `leveled-audio`.

### Features
- High-pass, noise reduction with automatic noise profile, handling-noise detection and reduction
- Adaptive leveler (default 130 %: also evens out large microphone-distance changes)
- Compressor, optional pause gate
- Loudness normalization (EBU R128, per file or as album) and true-peak limiter
- Presets (`podcast-stereo`, `podcast-mono`, `podcast-kraeftig`, `ebu-r128`) and your own TOML presets
- JSON report with schema
- Desktop app: exports next to the original file (`name-leveled-<preset>.wav`)

### Deutsch

Erstes Release von **Leveled Audio**: Stapelbearbeitung von Sprachaufnahmen (WAV), offline und ohne Installation. Mit Programmoberfläche (Englisch/Deutsch) und Kommandozeilenwerkzeug `leveled-audio`.

**Funktionen:** Hochpass, Rauschreduktion mit automatischem Rauschprofil, Erkennung und Absenkung von Griffgeräuschen, adaptiver Leveler (Standard 130 %: gleicht auch große Abstandswechsel aus), Kompressor, optionale Pausen-Absenkung, Lautheitsnormalisierung (EBU R128, pro Datei oder als Album), True-Peak-Limiter, Presets und eigene TOML-Presets, JSON-Report. Die Oberfläche legt jede Datei neben dem Original ab (`Name-leveled-<Preset>.wav`).

**Downloads:** siehe Tabelle oben. Unter macOS liegt `Leveled Audio.app` im Universal-Archiv. Sie ist nicht notarisiert, deshalb beim ersten Start Rechtsklick → Öffnen → Öffnen. Unter Windows warnt SmartScreen eventuell: „Weitere Informationen“ → „Trotzdem ausführen“.

Prüfsummen: `SHA256SUMS.txt`. Anleitung: `ANLEITUNG.md` (Deutsch) / `GUIDE.md` (Englisch) im Archiv.
