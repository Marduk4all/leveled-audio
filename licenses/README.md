# Lizenzen eingebetteter Schriften (nur `leveled-audio-gui`)

Die grafische Oberfläche nutzt egui, das Schriften in das Programm einbettet
(Crate `epaint_default_fonts`):

| Schrift | Lizenz | Datei |
|---|---|---|
| Hack, Noto Emoji | SIL Open Font License 1.1 | `OFL-1.1-Hack-Noto.txt` |
| Ubuntu Light | Ubuntu Font Licence 1.0 | `Ubuntu-font-1.0.txt` |

Die Kommandozeile `leveled-audio` enthält keine Schriften.
